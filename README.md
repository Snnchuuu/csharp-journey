# C# Journey 🚀

A structured, hands-on repository for mastering C# and .NET from the ground up.

---

## 📚 Curriculum

- [ ] **01_Basics_And_Syntax:** Structure of a C# program, namespaces, entry points, input/output, formatting.
- [ ] **02_Data_Types_And_Memory:** Value types (`struct`) vs Reference types (`class`), Stack vs Heap, `ref` and `out`, boxing/unboxing.
- [ ] **03_Control_Flow_And_Methods:** Conditionals, loops, pattern matching, method overloading, optional/named parameters.
- [ ] **04_OOP_Fundamentals:** Encapsulation, constructors, auto-properties (`{ get; set; }`), access modifiers.
- [ ] **05_OOP_Inheritance_And_Polymorphism:** Inheritance, `virtual`/`override`, `abstract` classes, interfaces (`IComparable`, `IDisposable`).
- [ ] **06_Collections_And_Generics:** Generic collections (`List<T>`, `Dictionary<TKey, TValue>`), type safety, constraints.
- [ ] **07_Delegates_And_Lambdas:** Delegates, `Action<T>`, `Func<T>`, lambda expressions (`=>`), events.
- [ ] **08_LINQ:** Declarative data querying (`Where`, `Select`, `OrderBy`, `GroupBy`, `Aggregate`).

---

## 🛠️ How to Run

Navigate to any module and run:

```bash
dotnet run --project <Module_Folder_Name>
```

Build the entire solution:

```bash
dotnet build
```
