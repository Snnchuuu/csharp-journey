# C# Journey 🚀

A structured, hands-on repository for mastering C# and .NET from the ground up, aligned with university computer science curriculum.

---

## 📚 Curriculum

- [x] **01_Basics_And_Syntax:** Structure of a C# program, namespaces, entry points, interactive console I/O, string interpolation, and `int.TryParse` validation.
- [x] **02_OOP_Classes_And_Objects:** Classes vs Objects, encapsulation, backing fields, auto-properties (`{ get; set; }`), constructor overloading, and reference type memory behavior.
- [x] **03_OOP_Inheritance_And_Polymorphism:** Class inheritance (`:`), `base` keyword, `virtual`/`override` methods, and method hiding.
- [ ] **04_Exception_Handling:** Robust error handling with `try`/`catch`/`finally`, system exception hierarchy, and custom exception classes.
- [ ] **05_Strings_And_RegEx:** In-depth string manipulation, formatting, and regular expressions (`Regex`, pattern matching).
- [ ] **06_Collections_And_Generics:** Type-safe collections (`List<T>`, `Dictionary<TKey, TValue>`), generics architecture, constraints.
- [ ] **07_Delegates_And_Lambdas:** Function pointers evolution in .NET: `Action<T>`, `Func<T>`, lambda expressions (`=>`), events.
- [ ] **08_LINQ:** Declarative data querying (`Where`, `Select`, `OrderBy`, `GroupBy`, `Aggregate`).

---

## 🛠️ How to Run

Navigate to any module and run:

```bash
dotnet run --project <Module_Folder_Name>
```

Build the entire solution:

```bash
dotnet build
```
